# Демо: ИИ-агент для карточек Яндекс.Карт

Демонстрационный прогон мультиагентной системы на реальной карточке организации:
аудит карточки → сравнение с четырьмя конкурентами из той же выдачи → находки P0/P1/P2 →
готовый к вставке пакет правок → схема конвейера из восьми агентов.

**Живая страница:** https://alex1986-rgb.github.io/yandex-maps-agent-demo/

Данные о карточках сняты 29.08.2026 из публично доступных страниц Яндекс.Карт.
Страница не связана с Яндексом; рейтинги и отзывы принадлежат их владельцам.
